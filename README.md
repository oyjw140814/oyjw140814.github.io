# 嘉文的个人作品集

粉金色黄昏湖面、Three.js 粒子 J、衬线大标题与六个作品。单个 `index.html` 包含内联 CSS 和一个 ES-module 脚本，无需构建。

## 本地预览

```sh
python3 -m http.server 8080
```

打开 http://localhost:8080 。Three.js 和字体通过 CDN 加载；加载失败时使用静态渐变背景，作品与导航仍可使用。

包括桌面和手机布局、项目分类、作品详情、GitHub 链接、声音与动画开关、键盘导航和减少动态效果支持。环境声音默认关闭。

六个作品以实际操作录屏剪成静音循环演示：岚汐纪恢复薄荷金色极光版本，宠语图鉴保留暖白萌宠手账；情绪织梦机采用浅紫丝绸信笺，情绪织物采用暖陶色编织工作室，ZPD 采用纸质机密档案，潜意识恐惧博物馆采用暖石色画廊。各作品分别设计背景、纹理和装饰，配有浮动画框、镜头推进、动态字幕与空间转场，替换原先的作品图；保留实际界面截图作为视频封面和加载失败时的备用图。视频靠近屏幕才加载，同时最多播放两个，离开屏幕、切换后台或关闭动画时暂停。每张卡片也可单独暂停或播放；点击卡片或“观看演示”可用原生控制条观看完整演示。减少动态效果模式下默认显示静态封面，可手动播放。

视觉参考用户提供的 Kinova 动态网站提示词，首页场景用 Three.js 实时生成。

部署：GitHub Pages，仓库 `oyjw140814.github.io`，`main` 分支根目录。

`assets/demos/` 为网页演示 MP4，`assets/projects/` 为优化后的 WebP 封面。录屏、剪辑时间线和发布包保存在本机“作品介绍视频”目录；聊天盘点文档、开发缓存及原素材不纳入公开仓库。
